# Filing-day checklist — ROUNDS CODEX trademark

One page, meant to be worked top to bottom on the day you file. Every field has the exact value to
enter. Written 2026-08-05; **not legal advice.** Fees/system names verified Aug 2026 — glance at the
running total on the form's payment screen before you pay. Full reasoning is in `trademark-plan.md`.

Fill the four blanks marked `⟨…⟩` before you start — they're the only things this file can't give you.

| blank | value |
|---|---|
| ⟨STATE⟩ | state where Rounds Codex, Inc. is incorporated |
| ⟨ADDRESS⟩ | business domicile address (**becomes public record** — not a home address) |
| ⟨OFFICER⟩ | your name + corporate title (e.g. President / CEO) — the signer |
| ⟨EMAIL⟩ | an inbox you'll still read in 3–6 years (renewals depend on it) |

---

## 0 · Pre-flight (must be true before you open the form)
- [ ] USPTO.gov account created, **ID.me identity verification complete** (see the plan — ~15–30 min).
- [ ] Logged in at **uspto.gov → Trademarks → Trademark Center**.
- [ ] Payment method ready. **Base fee to expect: $700** ($350 × 2 classes).

## 1 · Mark
- [ ] Filing type: **standard character mark** (NOT stylized / design).
- [ ] Mark literal element — type exactly: **`ROUNDS CODEX`**
- [ ] Do **not** claim color, and do **not** upload a logo. (Words in any font is the broader right.)

## 2 · Owner
- [ ] Owner name: **`Rounds Codex, Inc.`**
- [ ] Entity type: **Corporation**
- [ ] State/country of incorporation: **⟨STATE⟩**
- [ ] Domicile address: **⟨ADDRESS⟩**
- [ ] Email for correspondence: **⟨EMAIL⟩**

## 3 · Filing basis
- [ ] **§1(b), intent to use.** (App is unlaunched — do NOT pick §1(a) use-in-commerce, and do NOT
      attach a specimen. The specimen comes later, with the Statement of Use.)

## 4 · Classes + goods/services — the step that controls the fee
**Use the ID Manual picker built into this step. Search, tick approved entries, let it insert the
text. Typing your own sentence = +$200 per class.** Search terms below; take the approved entry that
comes back. The *target wording* is what a good match looks like — not text to paste.

- [ ] **Class 009** — search `downloadable software educational instruction`, narrow with
      `medicine`, `nursing`. Pick an entry that says what the software **does** *and* names the
      **field**. Add the `mobile application` variant too. Target shape:
      > Downloadable computer software for providing educational instruction, testing, and
      > assessment in the fields of medicine and nursing; downloadable mobile applications for the
      > same.
- [ ] **Class 041** — search `providing on-line instruction` and `providing on-line
      non-downloadable`, narrow with `medicine`, `nursing`. Keep the word **"non-downloadable."**
      Target shape:
      > Educational services, namely, providing online instruction in the fields of medicine and
      > nursing; providing online non-downloadable illustrated reference guides and practice
      > examinations in the same fields.
- [ ] Keep each class's identification tight — **each extra 1,000 characters is +$200/class.**

## 5 · Sign + pay
- [ ] Signatory: **⟨OFFICER⟩**, an officer of the corporation.
- [ ] Confirm the running total reads **$700** (two classes, no surcharges). If it's higher, a
      free-form description or an incomplete field slipped in — fix it before paying.
- [ ] Submit.

## 6 · The moment after you file — do not skip
- [ ] **Write the serial number here → `___________`** and into `trademark-plan.md`.
- [ ] Docket **two** reminders:
  - [ ] Check status in **TSDR monthly** (tsdr.uspto.gov).
  - [ ] A hard alarm for any **office-action response deadline**. **Missing it abandons the
        application** — the single most common way a self-filed mark dies.
- [ ] Expect **months**, not weeks, before an examiner picks it up.

---

## Do NOT
- ❌ Use the **®** symbol anywhere (app, listing, artwork) until registration *issues*. ™ is fine now.
- ❌ File §1(a) or attach a specimen — you're §1(b).
- ❌ Type your own goods/services text if an ID Manual entry fits.

## Later (not filing day)
- After launch: file the **Statement of Use** with an **App Store screenshot** as the specimen
  (separate per-class fee; extension fees if launch slips).
- The **logo/design mark** waits until the word mark's fate is known (it's already covered by
  copyright meanwhile).
